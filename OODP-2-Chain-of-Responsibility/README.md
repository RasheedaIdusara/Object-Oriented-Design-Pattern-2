# Chain of Responsibility Design Pattern

## 1. Introduction
Chain of Responsibility is a Behavioral Design Pattern.

## 2. Purpose
Pass a request through a chain of handlers until an appropriate handler processes it.

## 3. Real-World Example
A hospital patient consultation system.

## 4. Main Components
- Handler: Abstract Doctor
- Concrete Handlers: GeneralDoctor, SpecialistDoctor, Consultant
- Client: Main Class

## 5. Advantages
- Reduces coupling
- Improves flexibility
- Makes the system easier to extend
