## 1. About This Repository

This repository is dedicated to learning and practicing **Object-Oriented Design Patterns (OODP)** using Java.

It focuses on three major categories of design patterns:

- **Creational Patterns** – Focus on object creation mechanisms.
- **Structural Patterns** – Focus on organizing classes and objects into flexible structures.
- **Behavioral Patterns** – Focus on communication and responsibilities between objects.

The course also introduces **Compound Patterns, MVC architecture, and common software Anti-Patterns**.

## 3. Course Topics and Learning Roadmap

The **Object-Oriented Design Patterns – II** course covers the following design patterns.

### Creational Design Patterns

| Pattern | Main Purpose |
|---|---|
| Builder | Constructs complex objects step by step |
| Prototype | Creates new objects by cloning existing objects |

### Structural Design Patterns

| Pattern | Main Purpose |
|---|---|
| Decorator | Adds new functionality to objects dynamically |
| Composite | Treats individual objects and groups uniformly |
| Bridge | Separates abstraction from implementation |
| Flyweight | Reduces memory usage by sharing common object data |

### Behavioral Design Patterns

| Pattern | Main Purpose |
|---|---|
| Chain of Responsibility | Passes requests through a chain of handlers |
| Interpreter | Interprets expressions based on a defined grammar |
| Mediator | Centralizes communication between objects |
| Memento | Saves and restores object states |
| Visitor | Adds operations without modifying existing element classes |

**Note:** This table represents the course syllabus. Not all patterns listed above have been implemented in this repository yet.

## 4. UML Class Diagrams

UML (Unified Modeling Language) class diagrams help visualize the structure and relationships between classes.

The practical documentation uses UML diagrams to explain concepts such as:

- Inheritance
- Interface Implementation
- Association
- Aggregation and Composition
- Object Dependencies
- Polymorphism

These diagrams make it easier to understand how different classes collaborate within a design pattern.

## 5. Compound Patterns and MVC

The course also introduces **Compound Patterns**, which combine two or more patterns to solve larger software design problems.

### Model-View-Controller (MVC)

MVC is an architectural pattern that separates an application into three responsibilities:

- **Model:** Manages application data and business logic.
- **View:** Presents information to the user.
- **Controller:** Handles user input and coordinates interactions.

The course discusses MVC concepts in the context of Java EE, Servlets, and JSP.

## 6. Understanding Anti-Patterns

In addition to design patterns, the course introduces common **Anti-Patterns**.

Anti-patterns are recurring approaches to software development that may appear convenient but often lead to poor maintainability, unnecessary complexity, or other problems.

The course covers:

1. Spaghetti Code
2. God Object
3. Copy-Paste Programming
4. Long Method
5. Tight Coupling
6. Primitive Obsession
7. Magic Numbers and Strings
8. Swallowed Exceptions

Understanding anti-patterns helps identify poor design decisions and improve code quality.
